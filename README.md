# okizeme-video-scraper
A character move video scraper for the website okizeme.gg

# Background
I built this small app for the purpose of learning Tekken 8 character move frame data with flashcards (like Anki). Finding and downloading Tekken 8 character doing the moves were quite tedious so I built this so that I can easily reference the video for the move and insert it in my flashcards app. It was also a good reason to practice my Go programming skills.

If you stumble here, hope you find this useful as I do!

# Usage
I already included the .exe file so just open that. Enter the character name of the moves you'd like to download the application will take it from there. The app will create a folder with the name of the character you specified; **if a folder of said character already exists** **_it will delete the folder and everything inside_** so be careful where you place the .exe file.
